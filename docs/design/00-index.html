Recommendation

Ship 04 Split Signal, borrow 01's diff table and 02's typographic discipline.

Split is the only concept that survives every constraint at once: it keeps the light editorial craft that makes the pages readable, spends the entire 3D budget on a single hero panel that pauses offscreen and degrades to a static frame, and still carries a dark theme and one real interaction — the applied suggestion — which is the pattern the rest of the UI will need anyway.

  1. Base: 04's token layer and layout; every colour stays a custom property.
  2. Borrow from 01: the true diff gutter with per-line numbers and the +/- row tints, because that fidelity is what makes a reviewer trustworthy.
  3. Borrow from 02: the type scale — mono micro-labels at 10.5px, disciplined tracking, one accent word, and rules instead of card shadows.
  4. Keep from 03: only the dark palette, already folded into 04's theme.
  5. Cut: the second and third scenes. One is a signature; three is a performance budget you cannot defend.

What every concept already gets right

same story, same rules

One honest content spec

All four show the same finding on src/auth/session.ts (L42–L47), the same three steps, the same five setup fields, and the same three check-run states — including the quoted provider error. Nothing here invents product behaviour.

Accessibility is not a variant

Semantic landmarks, real buttons and links, 2px focus rings at 3px offset, 4.5:1 body contrast, labelled form controls, and a text caption for every canvas.

Motion that stops

Every scene pauses when offscreen, draws a single static frame under prefers-reduced-motion, caps device pixel ratio at 2, and never gates a call to action. No scroll-jacking, no autoplay, no third-party embeds.
