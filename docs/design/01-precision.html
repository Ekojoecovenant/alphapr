02 / how it works

Three steps, then it's out of your way.

There is no onboarding flow, no project to create, no prompt to write. Connect the app, let it read the diff, and trust the stored SHA to keep it quiet on the commits it has already seen.

  1. 01

    Connect

    Install the GitHub App at github.com/apps/alphapr-ai, then open /setup and paste your provider key. OpenRouter is verified in production; Anthropic and OpenAI adapters are implemented and contract-tested.

    /setup
  2. 02

    Review

    AlphaPR reads the diff and validates every line number before it comments, so findings land on the exact lines under review — with suggestion blocks the author can commit in one click.

    pull_request · synchronize
  3. 03

    Remember

    The last reviewed commit is stored per PR. A re-push reviews only new commits; an identical SHA is skipped. Draft PRs wait until they are ready, and [skip alphapr] in the title opts out.

    sha

Design notes
  • Palette rationale. White and GitHub's own hairline greys keep the page feeling like the surface the product lives on. Teal is rationed to links, one hero underline, and primary buttons; red appears only where the product would say major.
  • Motion budget. Three one-shot effects — a 6px rise on load (40/90/140ms delays), a single 1.4s sweep down the L42–L47 gutter, a 2px hover lift — plus one deliberate loop: the in-progress dot breathing at 1.8s. Nothing is scroll-triggered, and the reduced-motion branch stops all four without a script.
  • Cheap to port. The diff table and form are plain markup plus one stylesheet — template-string shaped, no components, no hydration, no bundler. Roughly 90% of this CSS would move into src/setup-pages.ts unchanged.
  • Expensive to port. Diff fidelity. Real line anchors, hunk boundaries, and severity tokens have to be emitted by the worker or the table degrades into a screenshot; that is server work, not styling work.
  • Zero network. No webfont, no image, no script, no analytics. First paint is the whole page, and the file behaves identically from file:// or a plane.
  • Accessibility. Landmarks and real links/buttons throughout, 2px offset-3px focus rings, body text above 4.5:1, and a reduced-motion branch that strips every animation and renders the final state immediately. The scrollable diff is a labelled region with tabindex="0" so it can be scrolled by keyboard.
  • Honest weakness. It is deliberately unmemorable. If the brief is "look like a 2026 startup", this reads as a GitHub settings page — and its density means the seven-row diff has to carry the entire story. The Apply-suggestion button is inert in the mockup.
