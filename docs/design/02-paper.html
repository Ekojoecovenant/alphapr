02 How it works

Three moves, and the loop closes.

No new dashboard and no new place to look. The whole loop lives inside the pull request you were already reading.

  1. 01

    Connect

    Install the app at github.com/apps/alphapr-ai, then open /setup and paste a provider key. OpenRouter is verified in production; Anthropic and OpenAI are implemented and contract-tested, not yet live-verified.

    One-time
  2. 02

    Review

    AlphaPR reads the diff, validates every line number against the files it was given, then comments inline — with a suggestion block whenever the fix fits in a few lines.

    Per push
  3. 03

    Remember

    The last reviewed commit is stored per pull request. A re-push reviews only new commits; an identical SHA is skipped as “Already reviewed”. Drafts wait, and [skip alphapr] in the title opts out.

    Per PR

+ Design notes 02 — Paper & Ink
  • 01

    Palette. Paper and ink carry the page; orange appears at most once per viewport — the italic word, the Apply affordance, a failure rule — so it reads as a mark, not a brand wash. Teal is reserved for added lines and the verified provider.

  • 02

    Motion budget. One 2D canvas (18 bars, only while on screen), a 46s marquee, a 5s gutter pulse, and 18px reveal rises. Everything pauses offscreen or hidden; reduced motion draws one static canvas frame and disables the marquee and pulse.

  • 03

    Cost to run. No libraries and no images: about 8KB of hand-written JS plus three Google Font families. After fonts, the whole concept is a single request.

  • 04

    Cheap to port. The markup maps 1:1 onto src/setup-pages.ts template strings — no components, no state, classes and one canvas. The setup panel is already the shape of the real form.

  • 05

    Expensive to port. The type ramp and asymmetric grid need real content; without Fraunces italic and mono labels it collapses into a blog. The canvas needs a static fallback if inline script is ever blocked by CSP.

  • 06

    Accessibility. Reveals are visible by default and armed only when observed, focus rings are 2px at 3px offset, mono is never the only label, and every state is stated in text as well as colour.

  • 07

    Honest weakness. Editorial whitespace is expensive: on a 14-inch laptop the sample review starts below the fold, and warm paper can read as “portfolio” to someone who wanted a dashboard. The 10.5px mono labels sit close to the legibility floor.
